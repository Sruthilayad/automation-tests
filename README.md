** Total: 20+ tests **

## How to Run

### Setup
```bash
npm install
...

### Run All Tests
```bash
npx playwright test
...
### Run Specific Test
```bash
npx playwright test tests/login.spec.js
npx playwright test tests/saucedemo.spec.js
npx playwright test tests/checkboxandradio.spec.js
...
### Run in browser(Headed)
```bash
npx playwright test --headed
...
